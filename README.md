# 📚 Sistema de Aprovação de Alunos

## 📝 Sobre o projeto

Este projeto foi desenvolvido para praticar meus conhecimentos em **HTML, CSS e JavaScript**, durante meus estudos de desenvolvimento Full Stack.

O programa tem como objetivo verificar a situação de um aluno com base em suas notas e frequência escolar.

## ⚙️ Funcionalidades

- Cadastro do nome do aluno.
- Entrada de três notas e da frequência.
- Cálculo da média das notas.
- Identificação da maior e menor nota.
- Verificação da situação do aluno: aprovado, recuperação ou reprovado.
- Validação dos valores informados.
- Exibição dos resultados na tela.

## 📋 Regras de aprovação

- **Aprovado:** média igual ou superior a 7 e frequência mínima de 75%.
- **Recuperação:** média entre 5 e 6,99 e frequência mínima de 75%.
- **Reprovado por nota:** média inferior a 5.
- **Reprovado por frequência:** frequência inferior a 75%.

## 💻 Tecnologias utilizadas

- **HTML5:** estrutura da página.
- **CSS3:** estilização da interface.
- **JavaScript:** cálculos, validações e manipulação dos elementos da página.

## 🎯 Objetivo de aprendizado

Com este projeto, busquei colocar em prática conceitos que estou aprendendo em JavaScript, como variáveis, funções, operadores lógicos, estruturas condicionais e manipulação do DOM.

Este é um projeto simples, desenvolvido como parte da minha evolução nos estudos de programação e desenvolvimento Full Stack.
